# Bongodevs

Open-source projects for music, audio, and the infrastructure around them.

[![Kairo CI](https://img.shields.io/github/actions/workflow/status/bongodevs/Kairo/rust.yml?branch=main&style=flat-square&label=Kairo%20CI)](https://github.com/bongodevs/Kairo/actions/workflows/rust.yml) [![Kairo stars](https://img.shields.io/github/stars/bongodevs/Kairo?style=flat-square&label=Kairo%20stars)](https://github.com/bongodevs/Kairo/stargazers) [![Kairo license](https://img.shields.io/github/license/bongodevs/Kairo?style=flat-square&label=license)](https://github.com/bongodevs/Kairo/blob/main/LICENSE)

We like building practical tools and sharing the work as we go. The projects here mostly focus on making audio services easier to run, connect, and extend.

## Projects

| Project | What it does |
| --- | --- |
| [Kairo](https://github.com/bongodevs/Kairo) | A Lavalink-compatible audio node written in Rust. |
| [Player](https://github.com/bongodevs/player) | Audio playback and track handling. |
| [Sources](https://github.com/bongodevs/sources) | Integrations for music and audio providers. |
| [Lyrics](https://github.com/bongodevs/lyrics) | Lyrics lookup and provider integrations. |
| [Voice](https://github.com/bongodevs/voice) | Discord voice transport. |
| [Keys API](https://github.com/bongodevs/keys-api) | Shared credential management for supported sources. |

## Contributing

Found a bug or have an idea? Open an issue in the project it relates to. Pull requests are welcome too—especially small changes with a clear explanation of what they improve.

Thanks for stopping by.
